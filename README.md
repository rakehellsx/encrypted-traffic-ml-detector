# 加密流量检测平台

**加密流量检测平台**是一套面向离线 PCAP 的机器学习分析系统。平台将原始报文归并为双向流，提取流统计、SPLT、TLS/QUIC 可见元数据并完成多分类检测；同时提供模型版本管理、完整检测详情、审计日志、历史归档及 CSV/JSON 导出能力。

| 能力 | 说明 |
| --- | --- |
| 样本上传 | 上传离线 PCAP，解析包数、流数与协议分布。 |
| 特征工程 | 提取五元组、包数、字节数、持续时间、包长、IAT、上下行比、SPLT 以及 TLS/QUIC 可见元数据。 |
| 多分类训练 | 支持正常流量、命令控制、数据外传、横向移动与恶意传输类别，使用 Logistic Regression 或 Gaussian Naive Bayes 训练。 |
| 离线检测 | 以指定模型分析 PCAP，给出逐流类别概率、风险等级、解释原因及完整特征详情。 |
| 历史归档 | 持久化训练数据、模型、检测任务和审计操作，支持检索、分页、详情查看与 CSV/JSON 下载。 |
| HTTP 接口 | `POST /api/v1/detect` 支持带 API Key 的 multipart PCAP 检测。 |

## 快速开始

项目使用 Node.js、React、Express、tRPC 与 Drizzle ORM。安装依赖并启动开发服务：

```bash
pnpm install
pnpm dev
```

常用质量验证命令如下：

```bash
pnpm test       # 单元测试
pnpm test:e2e   # PCAP 上传、训练、模型激活、检测、审计与历史导出端到端验证
pnpm check      # TypeScript 检查
pnpm build      # 生产构建
```

> 部署前请勿提交数据库密码、API Key、会话密钥或用户 PCAP。仓库中的 `.gitignore` 应保持对 `.env`、本地下载与构建输出的忽略规则。

## 公开访问与安全边界

Web 控制台当前工作于**公共工作区**模式，无需登录即可使用上传、训练、历史归档和检测界面。因此，应仅在受信任网络中部署该控制台，并配合网关访问控制、上传大小限制和存储生命周期策略。独立 HTTP 检测接口仍要求 `x-api-key`，密钥仅保存摘要，并支持在控制台内撤销。
